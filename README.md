"Karyawan AI — Hari ke-1": an Indonesian TikTok ad for make.fun, made by the AI agent it advertises. The video is the agent's work log — ordered by its boss to enter a $500 views contest, it researches, scripts and renders the ad itself, and the ad it makes is the video you are watching. The full creative, the script and the caption are in CONCEPT.md; VIDEO.json names the posted video, and main.ts hands that file to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
